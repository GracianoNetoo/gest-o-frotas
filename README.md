 Mini Sistema de Gestão de Frotas

Sistema web para gestão de pequenas frotas , focado em simplicidade, controle operacional e baixo custo.
Ideal para micro e pequenas empresas com até 15 veículos .

Visão Geral

Este projeto é um sistema de gestão de frotas que permite controlar veículos, motoristas, manutenções, abastecimentos e custos, organizado por planos de utilização.

O sistema foi pensado como um MVP escalável , começando simples e evoluindo conforme a necessidade do negócio.

Objetivo do Projeto

Centralizar informações da frota

Reduzir custos

Facilitar o controle de manutenções e abastecimentos

Oferecer um sistema simples para pequenas empresas
